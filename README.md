## master_updater - скрипт автоматического обновления `Astra Linux 1.8`
- Автор разработки `RC-Rick`
- Версия Alpha `0.7`
- Разработано для astraops.ru
***
## Для чего скрипт?
Для того, чтобы облегчить процесс обновления. Скрипт сам будет анализировать и производить обновление до нужной версии.
***
## Ключи запуска

| Ключ | Режим | Что делает |
|------|-------|------------|
| `-u` | auto | Обновляет систему по текущему `/etc/apt/sources.list` до последней доступной версии |
| `-m` | manual | Запрашивает параметры репозитория, предлагает список доступных версий и обновляет через подмену в `sources.list` |
| `-a` | astra-update | Обновляет систему через `astra-update` по текущему `/etc/apt/sources.list` |
| `-h`, `--help` | - | Показать справку и выйти |
| без ключей | - | То же, что `-h`: показать справку и выйти |

***
## Как работает каждый режим

### Автоматический (`-u`)
- Читает текущий `sources.list` (интернет-репозитории Astra Linux).
- Проверяет, что в `sources.list` указана только **одна** версия `astra_1.8.X`. Если найдено несколько - завершает работу с сообщением.
- Выполняет `apt-get update` и `apt-get dist-upgrade`.
- Если обновлять нечего - завершает работу с сообщением «Система уже обновлена».

### Ручной (`-m`)
- Спрашивает у пользователя параметры репозитория:
  - протокол (`http`/`https`),
  - IP или хост,
  - базовый путь (например `/repo`),
  - имя каталога `main` (по умолчанию `main-repository`),
  - имя каталога `extended` (по умолчанию `extended-repository`),
  - компоненты (`main contrib non-free non-free-firmware`).
- Показывает доступные для обновления версии из списка `VERSIONS_ORDER` (все версии выше текущей, но не выше `LATEST_FULL`).
- Пользователь выбирает нужную версию.
- Формирует `sources.list` под выбранную версию (каталог берется из `REPO_MAP`).
- Запускает `apt-get update` и `apt-get dist-upgrade`.
- Если на машине уже стоит `LATEST_FULL` - сообщает и завершает работу.
- Перед перезаписью сохраняет копию старого файла в `sources.list.back.YYYYMMDDHHMMSS`.

### astra-update (`-a`)
- Проверяет, что в `sources.list` указана только одна версия `astra_1.8.X`.
- Выполняет `apt-get update`.
- Запускает `astra-update -r -T -A`.
- Рекомендуется при переходе с `1.8.1` на `1.8.2`.

## Настройка под свою инфраструктуру

В начале скрипта заданы значения по умолчанию - их можно поправить прямо в файле:

```bash
REPO_PROTO="http"
REPO_HOST=""
REPO_BASE=""
REPO_MAIN_DIR="main-repository"
REPO_EXT_DIR="extended-repository"
REPO_COMP="main contrib non-free non-free-firmware"
